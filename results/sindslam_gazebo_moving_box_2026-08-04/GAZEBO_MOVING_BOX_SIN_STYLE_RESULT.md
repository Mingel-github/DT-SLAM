# Gazebo 移动箱子片段：SIn 风格四模式结果

日期：2026-08-04

## 1. 实验范围

复用此前录制并转换为 TUM 格式的 Gazebo 人＋箱子数据：

```text
/data/dynaslam/datasets/dtslam_gazebo_person_box_tum_run1_2026-08-01
```

本轮只取 `associations.txt` 第 4001–4600 行，共 600 帧、约 30 秒。该片段对应西侧移动箱子进入视野的阶段，用于避免完整 6846 帧环形走廊中的假回环主导结果。

运行模式与 TUM/Bonn 系统评测一致：纯 ORB-SLAM2、仅语义、仅 SIn 风格几何、语义＋几何。正式指标关闭 Viewer；之后额外进行了一次联合模式 Viewer 回放。

## 3. mask 与过滤统计

- 两个语义模式均得到 600/600 个同步 mask；语义动态像素总数为 0。
- 因此，仅语义与纯 ORB-SLAM2 的差异不能归因于语义误删；额外线程调度和 ORB-SLAM2 单次运行波动是可能解释，但本轮没有单独量化各自贡献。
- 仅几何在 597/600 帧输出非零几何区域。
- 仅几何累计标记 31,794 个 ORB 候选，约 53.0 个/帧。
- 仅几何删除有效深度约 20.71%；联合模式约 20.67%。
- 两个几何模式均未触发 Tracking fail-open，且轨迹完整。

## 4. 对失败的解释边界

可以确认：

1. 当前 SIn 风格配置在该仿真片段中过于活跃；
2. 初始约 12 个区域经 RAG 合并后常只剩 6–7 个大区域；
3. 日志中多帧几何区域达到数万至十余万像素；
4. 大面积删除没有带来 ATE/RPE 改善。

合理但尚未完全证明的机制解释：

- 全局 homography 不能完全补偿具有明显深度层次的走廊视差，静态墙面、地面和物体边界可能产生残余流；
- RAG 区域过度合并后，局部高残差会使较大静态区域一起被判为动态；
- 移动箱子表面 ORB 支持较少，而静态砖墙纹理产生大量特征，删除错误静态区域的代价可能超过删除箱子观测的收益。

本结果不能单独证明其中任何一个机制是唯一原因，也不能否定 Bonn 上已经观察到的正面结果。它证明当前区域参数和运动补偿不具备无需校准的跨域稳定性。

## 6. 同位姿建图对照

为将建图效果与定位差异分离，离线导出了两份使用完全相同几何模式位姿、帧、深度范围和像素采样的点云：

- 未过滤：保留所有有效深度；
- 过滤：只排除 S3 建图侧动态深度 mask 内的像素。

共使用 299 个采样帧（每 2 帧一次）、像素步长 8、最大深度 6 m。第 0 帧因没有光流参考而没有 mask，其余所有帧均匹配到位姿。

| 指标 | 未过滤 | S3 过滤后 | 变化 |
| --- | ---: | ---: | ---: |
| 采样点数 | 1,025,622 | 791,311 | 删除 234,311（22.85%） |
| 5 cm 唯一体素 | 56,623 | 53,113 | 完全删除 3,510（6.20%） |

时间支持度审计结果：

| 体素在采样帧中出现次数 | 体素数 | 被完全删除比例 | 观测次数删除比例 |
| --- | ---: | ---: | ---: |
| 1 次 | 9,257 | 25.60% | 25.60% |
| 2–3 次 | 11,859 | 5.11% | 11.13% |
| 4–7 次 | 12,816 | 2.49% | 12.79% |
| 至少 8 次 | 22,691 | 0.95% | 16.34% |

这些数据支持一个有限的正面结论：S3 更容易彻底清除只短暂出现的空间点，同时大多数长期稳定体素仍保留至少一次观测。这与“减少移动物体残影”一致，但不是物体真值证明。

代价同样明显：高时间支持体素的观测次数仍被删除 16.34%，表明部分帧中的稳定表面也被 mask 覆盖。它们通常没有被整体挖空，但点密度会下降。低支持还可由视角覆盖、遮挡、位姿误差或体素量化造成，因此不能把所有低支持点都解释为动态物体。

原始数据保存为：

- `map_same_pose_summary.json`：点数对照；
- `map_temporal_voxel_support.json`：时间体素支持度；
- `map_unfiltered_stride8_step2.ply/.pcd`：未过滤点云；
- `map_geometry_filtered_stride8_step2.ply/.pcd`：S3 过滤点云。

### 6.1 箱子真值覆盖审计

点云人工检查显示：箱子残影虽然密度下降，但移动轨迹仍明显存在；静态结构的损失则难以察觉。为解释这一现象，进一步使用 ROS 2 录包中的 `/box_odom`、`/odom`、已知相机外参和 0.6 m 立方体尺寸，将每帧深度点变换到箱子坐标系，得到可见箱子深度像素的仿真真值代理。

| 箱子覆盖指标 | 结果 |
| --- | ---: |
| 箱子足够可见的帧 | 143 |
| 按箱子像素数加权的 S3 覆盖率 | 64.15% |
| 逐帧箱子覆盖率中位数 | **0%** |
| 箱子覆盖低于 25% 的帧 | 82/143 |
| 箱子覆盖至少 75% 的帧 | 58/143 |
| 全部 599 帧 mask 像素中属于箱子的比例 | 3.60% |
| 箱子可见帧 mask 像素中属于箱子的比例 | 15.49% |

检测呈明显的尺度依赖：

| 按箱子图像面积四分位分组 | 平均 S3 覆盖率 | 中位覆盖率 |
| --- | ---: | ---: |
| 最小四分之一 | 6.46% | 0% |
| 次小四分之一 | 8.32% | 0% |
| 次大四分之一 | 50.96% | 66.17% |
| 最大四分之一 | 98.47% | 100% |

因此，64.15% 的像素加权覆盖率不能解释为“每帧删掉箱子的约三分之二”。真实行为是双峰型的：箱子较小或较远时长时间几乎完全漏检，箱子靠近并占据较大画面后才接近整体删除。每个漏检帧的深度点在简单累计点云中都会永久保留，因而只会降低残影密度，无法消除箱子移动轨迹。

另一方面，静态表面由大量帧重复观测；某些帧误删后，其他帧仍会将相同墙面或地面写入点云。这解释了“全局 mask 过于活跃，但静态点云空洞并不明显”。

可视化中绿色为箱子真值边界，红色为 S3 mask，黄色为两者交集：`box_gt_mask_audit/contact_sheet.png`。逐帧数据和摘要分别保存在 `box_gt_mask_audit/per_frame.csv` 和 `box_gt_mask_audit/summary.json`。

## 7. 结论

这是一个有价值的负结果：

- 该片段没有完整环形路线的假回环干扰，纯 ORB-SLAM2 已达到 2.86 cm ATE；
- 移动箱子没有严重破坏原始定位；
- 当前几何却删除了约五分之一有效深度，并使 ATE 上升。

建图结果只能记为部分有效：相同位姿下，S3 显示出优先清除低时间支持点、保留大多数高支持结构的倾向，但箱子真值审计证明这主要表现为降低残影密度，而不是消除移动箱子。静态地图主体依靠重复观测得以保留，但 22.85% 的点观测删除量也证明该 mask 存在大量箱子外覆盖。

因此，当前准确说法是：该仿真片段中几何方法没有改善定位；建图侧也没有清除移动箱子，只是减少了部分残影点。箱子较小/较远时的长时间漏检是直接原因；它是由流残差证据不足、固定像素尺度的轮廓/簇支持条件、还是区域表示造成，仍需在管线中间阶段与箱子真值对照才能区分。不能直接为仿真调整一个经验阈值后宣称解决。
