# Gazebo 固定轨迹离线 Mapping 可行性结果

日期：2026-08-06

## 1. 目的与范围

本实验只回答：

> 当前端漏检箱子时，后续 occupied/free 多帧证据是否有能力清除已经写入的箱子残影？

冻结：

- 同一段 Gazebo 600 帧移动箱子序列；
- 每2帧取1帧，共299个有S3 mask的采样帧；
- RGB-D、相机内参和最大深度6 m；
- 相机轨迹不因建图方法改变；
- 当前 S1/S2/S3 detector、Tracking 和 ATE 均不改变。

本轮不是：

- 在线 Mapping 实现；
- ROS1 节点；
- SInDSLAM完整建图复现；
- OctoMap参数优化；
- 将 Gazebo 箱子真值送入正式算法。

## 2. 方法身份

使用系统安装的 OctoMap 1.9.7 标准 hit/miss 概率更新：

```text
p_hit             = 0.7
p_miss            = 0.4
occupancy threshold = 0.5
clamping min/max  = 0.1192 / 0.971
```

`[L]` 概率占用、自由空间射线和 unknown 状态来自 OctoMap。

`[S]` 本项目在固定轨迹下同时构建五种地图，并用 Gazebo 箱子体积代理定义残影候选体素。

`[H]` 离线、稀疏采样结果能否转化为在线高分辨率 Mapping，尚未验证。

## 3. 五种对照

| 名称 | 含义 |
| --- | --- |
| raw endpoint union | 所有有效深度端点永久取并集，与普通累计点云对应 |
| stable endpoint hits | 只保留至少被3帧或8帧端点命中的体素，不使用free射线 |
| OctoMap all depth | 所有有效深度进入标准occupied/free更新，不使用动态mask |
| OctoMap＋S3 mask | S3动态像素整条射线跳过，其余深度进入概率地图 |
| oracle box filter＋OctoMap | 仅作上限；Gazebo箱子深度跳过，再进入概率地图 |

动态 mask 像素的射线保持 unknown，不把“被mask”错误解释为free。

## 4. 评价定义和边界

### 4.1 箱子残影候选

一个体素满足以下条件时记为 `box-exclusive ghost candidate`：

- 至少一次由 Gazebo 箱体深度命中；
- 从未被非箱子深度端点命中。

这样可排除与地面、墙面等静态端点重合的箱子轨迹体素，但它仍是仿真代理，不是现实数据可直接获得的标签。

### 4.2 持续非箱子参考

使用从未被箱子命中、但被非箱子深度端点命中至少3帧或8帧的体素，评价地图结构保留。

该参考仍可能包含运动人物，因此准确名称是：

> 持续非箱子体素保留率。

它不能被无条件称为静态地图 completeness。8帧版本比3帧版本更接近长期结构，但仍不是静态真值。

## 5. 10 cm主结果

### 5.1 使用纯ORB-SLAM2估计轨迹

该轨迹在此片段中的 ATE RMSE 为0.028619 m。所有建图模式共享这条轨迹，因此本实验不会产生不同ATE。

1047个箱子残影候选体素中，965个在箱子最后一次命中后被非箱子深度射线再次穿过：

```text
后续自由空间可清理比例 = 92.17%
```

| 地图 | 箱子残影保留率 | ≥3帧持续非箱子保留率 | ≥8帧持续非箱子保留率 |
| --- | ---: | ---: | ---: |
| 原始端点并集 | 100% | 100% | 100% |
| 仅时间命中支持 | 26.65%（≥3帧）/ 6.69%（≥8帧） | 100% | 100% |
| OctoMap，全深度 | **2.39%** | 65.77% | 69.88% |
| OctoMap＋当前S3 mask | **0%** | 65.06% | 69.60% |
| Oracle箱子过滤＋OctoMap | **0%** | 65.79% | 69.90% |

结果说明：不使用任何动态 mask，仅靠后续自由空间更新，箱子专属残影候选已从100%降到2.39%。当前S3 mask与概率更新组合后降为0%。

但概率占用地图只保留约70%的≥8帧持续非箱子参考，说明估计位姿、射线模型、体素量化和动态人物会共同造成明显结构损失。当前结果不是可直接上线的高质量地图。

### 5.2 使用Gazebo真值相机轨迹

这组只用于区分位姿误差与地图更新本身的代价。

1027个箱子残影候选中，920个在最后箱子命中后存在后续非箱子自由射线：

```text
后续自由空间可清理比例 = 89.58%
```

| 地图 | 箱子残影保留率 | ≥3帧持续非箱子保留率 | ≥8帧持续非箱子保留率 |
| --- | ---: | ---: | ---: |
| 原始端点并集 | 100% | 100% | 100% |
| 仅时间命中支持 | 15.87%（≥3帧）/ 7.30%（≥8帧） | 100% | 100% |
| OctoMap，全深度 | **1.17%** | 81.79% | 87.55% |
| OctoMap＋当前S3 mask | **0%** | 79.99% | 85.93% |
| Oracle箱子过滤＋OctoMap | **0%** | 81.82% | 87.58% |

真值位姿将≥8帧持续非箱子保留率从纯ORB轨迹的69.88%提高到87.55%。因此，纯ORB轨迹下的结构损失有相当一部分来自位姿和射线对齐误差，而不只是OctoMap概率参数。

S3 mask额外降低约1.6个百分点的持续非箱子保留率，但将残影从1.17%进一步降到0%。这里的非箱子参考含人物，不能把全部降低解释为静态误删。

## 6. 5 cm分辨率敏感性

| 轨迹/地图 | 箱子残影保留率 | ≥3帧持续非箱子保留率 |
| --- | ---: | ---: |
| 纯ORB，OctoMap全深度 | 0.84% | 57.20% |
| 纯ORB，OctoMap＋S3 | 0.018% | 55.29% |
| 真值轨迹，OctoMap全深度 | 1.00% | 73.32% |
| 真值轨迹，OctoMap＋S3 | 0% | 71.11% |

5 cm下残影清理趋势仍然成立，但持续非箱子保留率进一步下降。这说明结果不是10 cm粗体素偶然产生的；同时也说明，更细体素在当前像素采样和位姿噪声下更容易出现表面错位与射线误清除。

不能由此选择“最佳分辨率”；本轮没有调参目标。

## 7. 对研究问题的回答

### 7.1 地图端是否有能力清理当前箱子轨迹？

**有，而且本段数据中的机会很强。**

约85%–92%的箱子专属残影体素在箱子离开后确实被后续非箱子射线穿过。标准概率占用在不使用动态mask时，已经清除了约97.6%–99.2%的候选残影；加入当前S3 mask后接近或达到100%。

这验证了此前假设：普通点云之所以保留整条箱子轨迹，很大程度上是因为它不会利用后续free-space证据撤销旧占用。

### 7.2 是否已经得到可用的最终地图？

**没有。**

主要问题：

- 10 cm体素过粗，不等于论文质量地图；
- 5 cm下结构保留对位姿和采样更敏感；
- “持续非箱子”仍混入人物，不是严格静态真值；
- 使用的是每2帧、每8像素采样的离线审计；
- 没有评价完整静态表面accuracy和completeness；
- 没有在线线程、内存和全分辨率成本；
- 没有证明真实Bonn/TUM也具有相同自由空间重访条件。

### 7.3 当前S3 mask是否仍有价值？

在该片段中，概率地图本身已去除绝大多数箱子残影；S3将剩余2.39%（纯ORB轨迹）进一步降到0%，但也略降低持续非箱子保留率。

因此最准确的说法是：

> 当前S3不是Gazebo残影清理的主要贡献者，但可作为概率地图的补充先验；真正改变结果的是地图不再永久保存每一次占用。

## 8. 工程与论文含义

本实验支持“Tracking与Mapping差异化处理”的研究方向：

- Gazebo Tracking继续使用纯ORB轨迹即可保持较好定位；
- Mapping利用长期occupied/free证据清理漏检深度；
- Bonn等动态观测破坏位姿的场景仍需要前端几何过滤；
- 语义、几何和地图时间证据不应简单合并为一个无条件二值mask。

但本轮只验证了Mapping侧的物理可行性，不足以把它写成已完成方法。

## 9. 运行成本

在299帧、像素步长8下：

- 10 cm：约4.6–4.9 s；
- 5 cm：约15.8–16.6 s。

这些是离线稀疏采样审计速度，不能外推为全分辨率在线FPS。

## 11. 补充实验：S3过滤后再做时间支持筛选

在完全相同的纯ORB-SLAM2固定轨迹、299个采样帧、10 cm体素和像素步长8下，新增：

```text
S3 dynamic depth mask
→ 跳过当前动态深度端点
→ 对剩余端点逐帧累计体素命中次数
→ 分别要求至少3帧或8帧支持
```

这不是新的动态检测器，也不改变Tracking；它只比较“当前S3过滤”和“建图端正时间支持”的组合。

| Mapping方式 | 占用点数 | 箱子残影候选保留率 | 持续非箱子结构保留proxy |
| --- | ---: | ---: | ---: |
| S3后直接累计 | 11962 | 75.17% | 99.43%（≥3帧参考） |
| S3＋至少3帧 | 10407 | 14.71% | 97.49%（≥3帧参考） |
| S3＋至少8帧 | 7963 | **0%** | 94.48%（≥8帧参考） |
| S3＋OctoMap | 6998 | **0%** | 69.60%（≥8帧参考） |

对应的无S3结果为：至少3帧保留26.65%的箱子候选，至少8帧保留6.69%。因此，在本段数据中，S3先验与正时间支持具有可测的互补效果：

- 3帧规则由26.65%进一步降至14.71%；
- 8帧规则由6.69%进一步降至0%。

但“8帧＋S3为0%”只对当前**0.5 m/s匀速往返箱子**成立，不能外推为通用清理能力。控制代码固定发布0.5 m/s，只在Y轴±5 m边界直接反转方向；保存的6845个相邻轨迹区间平均速度为0.4993 m/s，仅18个低于0.45 m/s的瞬时区间，均位于换向点，没有持续低速或停留阶段。因此现有录像不能用于评价慢速或暂时静止物体。一般而言，若另一个动态物体在同一体素停留超过8个未屏蔽采样帧，它可能通过该规则；这是尚未由当前数据测试的能力边界，而不是当前序列的解释。相反，只被少数视角看到的真实静态表面也可能被删除。OctoMap的0%来自不同机制：它还会利用后续free-space射线撤销旧占用。

## 11. 最终结论

> 固定轨迹离线实验通过了“地图端是否有清理潜力”的可行性检查。Gazebo相机在箱子离开后重新观测了绝大多数旧箱子位置，自由空间概率更新能够把普通点云中的连续箱子轨迹大幅清除。当前未解决的问题已经从“有没有清理证据”转为“如何在保留静态结构、容忍位姿误差的前提下使用这些证据”。
