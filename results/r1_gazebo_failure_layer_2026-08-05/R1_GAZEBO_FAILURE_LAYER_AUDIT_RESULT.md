# R1 Gazebo 失败层只读审计结果

日期：2026-08-05
基线：R0 commit `6c29ff8`
性质：只读诊断；没有修改几何判决、Tracking、Mapping或阈值

## 1. 结论先行

Gazebo移动箱子的漏检不是由一个单独的区域传播错误造成，而是具有明确的级联结构：

```text
箱子距离大于6 m
→ 当前配置不为该深度生成区域
→ 56/199个可见箱子帧必然无法形成箱子区域

箱子进入6 m以内、但仍处于中远距离
→ 区域通常已经正确覆盖箱子
→ 箱子光流残差仍普遍低于当前约3 px的high阈值
→ 82/143帧因“高残差像素不足”被拒绝

箱子较近且图像运动明显
→ 高残差证据充足
→ 60帧区域被接受，其中58帧最终箱子覆盖超过75%
```

因此，当前证据不支持优先修改区域邻接图、普通区域生长或固定面积条件。中远距离漏检时，区域表示大多已经可用，但进入分类器的高残差证据为零；只降低“最少100个高残差像素”也不会恢复这些帧。

下一项有依据的单变量实验应为 R2：在完全冻结稠密光流、区域标签、分类器和时序状态的条件下，对比当前全局 homography、静态像素 oracle homography、Gazebo参考位姿 RGB-D/SE(3) 和 ORB-SLAM2在线位姿 RGB-D/SE(3) 的相机运动补偿。该实验首先判断大面积地面/墙面残差是否来自全局 homography 对三维视差的近似，而不预设 SE(3) 一定能够恢复远小箱子。

## 2. 执行内容

- 稠密观测光流；
- current-to-reference homography；

## 3. 自动箱子参考的证据边界

离线工具使用Gazebo相机位姿、箱子位姿、已知0.6 m立方体尺寸和当前实测深度，把落入箱体体积的可见RGB-D点记为：

> simulator-derived visible-box reference

它是仿真器信息构成的可见箱体参考，不宣称像素级完美真值。箱子以外还可能包含运动行人，因此报告使用`non-box`，不把所有箱外像素叫做静态背景。

600帧中：

- 箱子可见且参考像素不少于100：199帧；
- 箱子参考像素为0：399帧；
- 其余2帧只有极少箱体像素，不进入主要箱体统计。

## 4. 分层结果

### 4.1 距离超过6 m：区域生成被配置直接截断

当前冻结配置为：

```text
SInStyle.NativeMaximumDepthM = 6.0
```

199个可见箱子帧中有56帧箱子中位深度超过6 m。在这些帧中：

| 指标 | 结果 |
| --- | ---: |
| 初始区域箱体覆盖中位数 | 0 |
| 梯度区域箱体覆盖中位数 | 0 |
| RAG区域箱体覆盖中位数 | 0 |
| 最终箱体覆盖中位数 | 0 |
| 主要代码原因 | `no_box_region`，56/56 |

这是一个确定的区域层限制，不是推测。不过，这56帧的箱体观测光流中位数仅约0.56 px，homography残差中位数约0.54 px，高残差覆盖中位数为0。因此，仅把区域最大深度从6 m调大也没有证据能够恢复动态判决；它只会让更多低信号远距像素进入区域链。

### 4.2 6 m以内漏检：区域通常正确，动态残差信号不足

箱子位于6 m以内的143帧中，82帧最终箱体覆盖低于10%。这些漏检帧的中位数为：

| 指标 | 中位数 |
| --- | ---: |
| 箱体深度 | 4.52 m |
| 箱体像素 | 6279.5 |
| 箱体观测光流 | 1.68 px |
| 箱体邻近环带观测光流 | 1.15 px |
| 箱体homography残差 | 0.42 px |
| 邻近环带homography残差 | 0.72 px |
| 当前high阈值 | 3.00 px |
| 初始区域箱体覆盖 | 97.3% |
| RAG区域箱体覆盖 | 95.9% |
| 箱体主区域纯度 | 100% |
| 箱体high证据覆盖 | 0% |
| 最终箱体覆盖 | 0% |

这82帧的精确分类器拒绝原因全部为：

```text
insufficient_high_pixels
```

重要的是，箱体内high像素本身为零。因此，“最少100个high像素”是表面的执行分支，但当前数据不支持把固定面积门槛称为根因。即使把100改小，只要输入high mask仍为空，结果不会改变。

### 4.3 近距离阶段：现有链路能够完整检测箱子

最终箱体覆盖超过75%的58帧中：

| 指标 | 中位数 |
| --- | ---: |
| 箱体深度 | 1.93 m |
| 箱体像素 | 20130 |
| 箱体观测光流 | 8.81 px |
| 邻近环带观测光流 | 2.97 px |
| 箱体homography残差 | 4.80 px |
| 邻近环带homography残差 | 1.11 px |
| RAG区域箱体覆盖 | 96.8% |
| 箱体high证据覆盖 | 85.0% |
| 最终箱体覆盖 | 99.99% |

这些数据表明，箱体运动证据足够强时，当前区域和分类器可以工作。不能据此声称跨尺度可靠，但也不能把所有失败归因于区域表示。

### 4.4 精确分支计数

在199个主要可见箱子帧中，箱体主区域的判决为：

| 原因 | 帧数 | 含义 |
| --- | ---: | --- |
| `no_box_region` | 56 | 箱体在区域最大深度之外 |
| `insufficient_high_pixels` | 82 | 区域存在，但high证据不足 |
| `contour_geometry_rejected` | 1 | high轮廓未通过现有形状条件 |
| `accepted_partial_region` | 20 | 接受部分区域 |
| `accepted_whole_region` | 40 | 接受整个区域 |

把实际区域替换为可见箱体oracle区域后：

| Oracle结果 | 帧数 |
| --- | ---: |
| high证据仍不足 | 137 |
| 可形成有效seed | 60 |
| 轮廓几何拒绝 | 1 |
| 无low-support seed | 1 |

因此，oracle区域不能恢复大多数漏检帧。按预先冻结的停止规则，不应优先继续优化RAG或普通区域传播。

### 4.5 短时时序没有恢复中远距离箱子

- 时序新增证据与箱体重叠的可见帧：14/199；
- 可见箱体上的时序新增覆盖中位数：0；
- 箱子不可见帧中有295帧存在非零时序新增像素。

这些结果说明当前上一帧先验没有明显恢复中远距离箱子。箱外仍包含运动行人，所以295帧不能直接解释为错误传播；它只说明时序层不是当前箱体召回的主要来源。

### 4.6 大面积箱外mask仍需相机运动补偿对照

箱子不可见帧中的最终动态像素占有效深度比例中位数约18.98%。联系表中可直接看到地面、顶面和墙面出现大块high residual与最终mask，这与全局homography难以解释多深度三维视差的机制相容。

但本阶段没有像素级人物真值，不能把全部箱外mask统计直接称为静态误检。是否由homography模型能力、PROSAC估计、DeepFlow或真实行人运动造成，必须由R2的固定输入对照判断。

## 5. R1排除了什么

R1不支持以下下一步：

1. 继续调RAG合并参数；
2. 加普通连通域或flood fill；
3. 单独降低最少high像素数；
4. 把6 m最大深度简单扩大后直接上线；
5. 把箱外mask全部解释为静态误检；
6. 同时加入SE(3)、尺度阈值、plane edge和S4。

原因是：6 m以内漏检帧的区域覆盖和纯度已经较高，主要缺口发生在high residual形成之前；远距帧即便给oracle箱体区域，high证据也仍然不足。

## 6. 唯一建议的下一变量：R2运动补偿模型

R2固定：

- 同一DeepFlow观测；
- 同一参考帧；
- 同一有效像素；
- 同一region labels；
- 同一阈值生成算法；
- 同一classifier和temporal prior；
- 首轮只做离线/shadow，不影响SLAM。

只比较：

```text
当前PROSAC homography
静态参考像素拟合的oracle homography
Gazebo参考相机位姿 RGB-D/SE(3)
ORB-SLAM2事后轨迹 RGB-D/SE(3)（只作诊断上限）
历史位姿常速度预测 RGB-D/SE(3)（在线候选）
```

R2首先回答：

- 静态地面/墙面的广泛残差能否被深度感知SE(3)显著降低；
- 当前homography失败来自模型能力，还是估计过程；
- 事后ORB位姿是否接近参考SE(3)，以及历史常速度预测是否足以在线使用；
- 改进背景补偿后，箱体与背景的残差可分性是否真正提高。

边界：当前SIn检测在`Track()`之前运行，当帧ORB最终位姿尚不存在。事后轨迹只能用于诊断，不能直接上线；在线版本只能使用历史状态预测，且不得为获得当帧位姿而新增一次Tracking或第三次位姿优化。即便SE(3)减少背景误检，也未必恢复远距慢运动箱子。若Gazebo参考SE(3)下箱体残差仍不足，则后续应转向flow/时间基线或明确接受远小慢运动不可检测，而不是继续修改区域。

## 8. 最终结论

> R1已经把“远小箱子漏检”拆成两个可验证层次：超过6 m时箱子被区域最大深度明确排除；进入6 m后，区域通常完整且纯净，但中远距离箱体的observed flow与homography residual不足以形成high证据，82帧因此被精确拒绝。近距离高运动阶段现有链路可以几乎完整覆盖箱子。由此，下一步不应继续修区域或面积参数，而应先以固定输入比较homography与RGB-D/SE(3)相机运动补偿，并承认该实验主要针对背景残差，未承诺自动恢复远小慢运动箱子。
