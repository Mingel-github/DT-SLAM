## 1. 当前系统基线

当前系统主链为：

```text
ORB-SLAM2 RGB-D
+ YOLOv8-seg 同帧语义 mask
+ SInDSLAM 风格区域几何 mask
→ S2：动态 ORB 特征与新 MapPoint 写入控制
→ S3：动态深度 mask 与过滤后的建图深度
```

已经完成：

- YOLOv8n-seg CUDA 同步语义基线；
- S1：三维初始聚类、深度梯度切分、区域邻接合并、CPU DeepFlow、homography补偿、区域级动态判决和短时时序；
- S2：mask进入ORB匹配、局部位姿优化前关联清理及新MapPoint写入控制；
- S2强遮挡Tracking fail-open；
- S3：`dynamicDepthMask`与`staticDepthMeters`输出；
- TUM、Bonn和Gazebo四模式实验；
- 同位姿点云、体素时间支持及Gazebo箱子投影代理评价。

现有正面结果：

- TUM walking与Bonn非遮挡箱子定位改善明显；
- Bonn非遮挡箱子S2三轮结果具有重复性；
- Bonn点云中动态重影明显减少；
- 静态负样本没有观察到灾难性定位退化。

现有负面结果：

- Gazebo 600帧箱子片段中，纯ORB-SLAM2优于几何模式；
- 远小箱子经常完全漏检；
- 箱子不可见时仍普遍产生非零几何mask；
- S3只降低箱子残影密度，没有清除移动轨迹；
- CPU几何约3–5 FPS；
- 简单`semantic OR geometry`没有稳定优于geometry-only。

## 3. 总体执行原则

### 3.1 冻结输入

每轮对照必须固定：

- Git commit；
- 数据集与association；
- Gazebo帧范围；
- 相机内外参；
- DeepFlow输入和参数；
- region labels；
- classifier参数；
- temporal prior；
- ORB参数；
- Viewer关闭；
- OpenMP线程数；
- 随机种子；
- 轨迹和地图评价工具版本。

### 3.2 先shadow，后影响SLAM

任何新测量或候选改造必须先离线或shadow运行：

```text
读取冻结输入
→ 计算新证据
→ 不写mvbDynamic
→ 不清除mvpMapPoints
→ 不改变MapPoint
→ 不改变轨迹
```

只有中间层证据成立后，才允许进入端到端Tracking实验。

### 3.3 单变量改动

一次实验只改变一个核心机制。禁止同时加入：

- SE(3)补偿；
- classifier尺度阈值；
- plane edge；
- S4；
- OctoMap；
- 新语义融合；
- 新时序状态。

### 3.4 Oracle只用于诊断

Oracle输入只能回答：

> 如果这一层理想化，后续链路最多能够恢复多少性能？

Oracle不能直接成为最终算法，也不能被包装成实际检测结果。

### 3.5 Unknown不是Static

无效深度、投影越界、遮挡/显露、flow不可用和未覆盖区域均保持unknown。不得将这些位置直接解释为静态或自由空间。

## 5. R1：Gazebo失败层只读审计

### 5.1 目标

不改变detector行为，逐帧导出并评价：

```text
observed dense flow
homography ego-flow
residual magnitude
low/high residual masks
initial K-means labels
gradient split labels
RAG merged labels
per-region support
classifier decision reason
previous temporal state
final geometry mask
```

### 5.2 自动参考数据

优先使用Gazebo自动参考：

- `/box_odom`；
- 相机/底盘位姿；
- 相机外参；
- 0.6m箱体尺寸；
- 当前深度；
- 人物或其他运动体状态；
- 仿真世界几何。

术语使用：

> simulator-derived reference / Gazebo几何参考

在确认topic来源和同步前，不无条件称为pixel-perfect ground truth。

不把人工标注设为默认工作。只有自动参考无法回答某个问题时，才考虑极少量人工检查。

### 5.3 按物理条件分组

逐帧按以下变量分组：

- 箱子投影面积；
- 箱子深度；
- 箱子图像速度；
- 相机平移/旋转幅度；
- 遮挡比例；
- 箱子可见/不可见；
- 箱子与背景深度差；
- region purity和fragmentation。

### 5.4 各层需要回答的问题

| 层 | 核心问题 | 失败定义 |
| --- | --- | --- |
| Dense flow | 箱子像素的observed flow是否与背景可分？ | 即使使用可靠ego补偿，箱子残差仍无区分 |
| Ego compensation | 静态背景是否因补偿错误产生残差？ | 参考SE(3)显著降低背景残差 |
| Region | 箱子是否被混入背景或切得过碎？ | Oracle box region能恢复，而actual region不能 |
| Classifier | 上游证据正确时是否被像素/面积条件拒绝？ | classifier-only替换恢复小箱子且静态风险受控 |
| Temporal | 已检测区域是否被快速丢失或错误传播？ | 单帧证据存在但最终状态消失，或箱子不可见仍持续传播 |

### 5.5 Counterfactual replay

同时做两种替换：

#### 单层替换

```text
只替换flow
只替换ego compensation
只替换region
只替换classifier
```

#### 累积替换

```text
actual pipeline
→ reference ego
→ reference ego + oracle region
→ reference ego + oracle region + oracle classifier
```

报告每一层能够回收的箱子覆盖和背景风险，不强行要求唯一根因。

### 5.6 R1输出

- 每帧中间量索引；
- 分尺度/深度/运动分组CSV；
- 箱子与背景residual分布；
- region purity/fragmentation；
- classifier拒绝原因计数；
- temporal transition统计；
- 代表性contact sheet；
- 失败层审计报告；
- 对R2的唯一推荐变量。

### 5.7 R1停止条件

若上游某层已经无可分证据，不继续调其下游阈值。例如：

- flow无区分，不调classifier；
- reference SE(3)也无法降低背景残差，不改homography；
- oracle region仍无法恢复箱子，不继续优化RAG；
- classifier不是拒绝原因，不做尺度阈值。

## 6. R2：运动补偿单变量实验（仅在R1支持时）

### 6.1 候选对照

固定同一dense flow、region、classifier和temporal prior，仅比较：

1. 当前PROSAC homography；
2. 只使用Gazebo参考静态像素拟合的oracle-static homography；
3. Gazebo参考相机位姿RGB-D/SE(3)；
4. ORB-SLAM2 initial pose RGB-D/SE(3)。

### 6.2 方向约定

SInDSLAM论文从当前帧像素映射到上一帧：

```math
u_{t-1}^{flow}=u_t-v(u_t).
```

SE(3)版本保持相同方向：

```math
X_t=\pi^{-1}(u_t,D_t(u_t)),
```

```math
\hat u_{t-1}^{SE3}=\pi(T_{t-1\leftarrow t}X_t).
```

```math
\delta_{SE3}(u_t)=\|u_{t-1}^{flow}-\hat u_{t-1}^{SE3}\|.
```

实施前必须通过合成纯平移/纯旋转测试核对：

- DeepFlow调用顺序；
- flow符号；
- homography方向；
- `Tcw/Twc`与相对位姿方向。

### 6.3 两层评价

#### Residual层

- common-valid pixels上的配对差异；
- 全部像素valid coverage；
- 静态背景median/p90 residual；
- 箱子residual；
- 箱子/背景ROC-AUC和Precision–Recall；
- residual随深度、视差和图像位置变化。

#### 系统层

只有Residual层成立后，才进入：

- classifier输出；
- S2候选ORB；
- Tracking完整率；
- ATE/RPE；
- S3深度覆盖与地图指标。

### 6.4 解释矩阵

| 结果 | 结论 |
| --- | --- |
| oracle homography差、reference SE(3)好 | homography模型能力不足 |
| oracle homography好、current homography差 | 对应排序/先验/robust estimation问题 |
| reference SE(3)好、SLAM SE(3)差 | 在线初始位姿不足 |
| reference SE(3)也差 | 检查flow、深度、遮挡、同步和坐标域 |

### 6.5 R2放行条件

仅当某个在线可实现版本同时：

- 降低背景误残差；
- 保留或提高未知箱子证据；
- 不显著降低valid coverage；
- 在Bonn/Gazebo/静态留出场景不造成明显退化；

才允许成为DT-SLAM核心改造候选。

## 8. Tracking与Mapping任务分离

### 8.1 共享证据

长期建议保留统一中间表示：

```text
validity
motion evidence
source: semantic / geometry
region support
temporal support
tracking action
mapping action
```

不为Tracking和Mapping各自重新发明一套残差。

### 8.2 Tracking策略

Tracking重点是可观测性：

```text
高动态证据
+ 剩余静态匹配足够
→ 拒绝观测
```

unknown或中间证据默认保留给ORB-SLAM2原生鲁棒优化。现有fail-open继续作为安全层，但不能把被恢复特征解释为静态。

### 8.3 Mapping策略

Mapping重点是长期污染：

```text
accept static
reject dynamic
defer unknown
```

当前S3已有accept/reject输出，但尚无真正的defer缓存。只有实验证明需要延迟融合时，才设计新的历史状态；不在R1阶段增加。

## 9. R4：S4长时间隔Mapping精修

### 9.1 目的

处理相邻帧难以检测的：

- 慢速运动；
- 暂时停止；
- 间歇运动；
- 停留人物残影。

### 9.2 文献依据

依据SInDSLAM论文Eq. (17)：选取稀疏帧，使用ORB-SLAM2相对位姿进行深度重投影，将长时间隔深度不一致补充进Mapping mask。

### 9.3 与论文/源码的差异需先冻结

- 论文：每五帧一张sparse frame，描述为相邻sparse frames比较；
- 公开ROS源码：每五个输入帧发布一次，但缓存稳定后实际可能与更早sparse frame比较。

本项目必须明确选择自己的参考间隔，并将其标为论文改造，而不是同时声称两种行为。

### 9.4 输出

```text
M_map = M_short_term OR M_long_term
```

S4只影响建图深度，不进入Tracking。

### 9.5 能力边界

S4可能改善已被检测后停止或慢速的物体，但不能自动解决：

- 远小箱子从未产生flow/region证据；
- 箱子不可见时背景大面积误检；
- 相机位姿或坐标域错误。

## 10. R5：OctoMap作为独立Mapping后端评价

### 10.1 定位

OctoMap不是S1 detector，也不是ORB-SLAM2稀疏地图。它是：

```text
过滤后RGB-D
+ 相机位姿
→ occupied / free / unknown概率八叉树地图
```

优先离线或独立进程评价，不进入ORB-SLAM2优化闭环。

### 10.2 2×2消融

固定相同轨迹、帧、深度和地图参数：

| S4 | OctoMap | 输出 |
| ---: | ---: | --- |
| 关 | 关 | 当前S3普通累计点云 |
| 开 | 关 | S3＋S4普通累计点云 |
| 关 | 开 | 当前S3 mask＋OctoMap |
| 开 | 开 | S3＋S4 mask＋OctoMap |

额外增加：无动态mask＋OctoMap。

### 10.3 Masked ray语义

- 动态mask像素没有可信静态终点；
- 不把该方向直接更新为free；
- 该射线跳过更新，保持unknown；
- 只有未mask且深度有效的测量才更新沿途free和终点occupied。

### 10.4 固定参数

- voxel resolution；
- hit/miss probability；
- clamping范围；
- occupancy threshold；
- 最大深度；
- 像素采样；
- 输入帧；
- 相机位姿；
- masked pixel处理。

### 10.5 地图指标

优先在Gazebo测量：

- dynamic swept-volume ghost occupancy；
- static surface accuracy；
- static map completeness；
- free-space violation；
- 静态结构空洞；
- 高/低时间支持体素；
- 内存与运行时间。

不能只比较点数或截图。

### 10.6 OctoMap能力边界

- 只有后续free-space射线穿过旧ghost位置时，旧占用才会下降；
- 它没有自动时间遗忘的保证；
- 持续漏检的动态物体可能成为稳定占用；
- 没有后续观测的位置可能保留ghost；
- 它不能提高detector召回率，也不能修复位姿错误。

- semantic-only；
- geometry-only；

- ATE RMSE；
- RPE RMSE；
- trajectory completeness；
- LOST与relocalization；
- keyframes；
- 动态ORB覆盖；
- 静态ORB误删；
- object coverage；
- background false-mask risk；
- dynamic depth ghost；
- static accuracy/completeness；
- FPS和分模块耗时；
- median、IQR或均值与标准差；

## 12. 阶段放行与停止规则

| 当前证据 | 后续动作 |
| --- | --- |
| Dense flow在小箱子上无区分 | 研究flow，不改homography/region/classifier |
| Reference SE(3)也无法降低背景残差 | 检查flow、深度、遮挡、同步和坐标域 |

| OctoMap只改善截图、不改善地图指标 | 不进入主系统 |
