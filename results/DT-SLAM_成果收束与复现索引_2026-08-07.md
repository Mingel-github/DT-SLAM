# DT-SLAM 成果收束与复现索引

日期：2026-08-07

状态：系统型研究版本收束；不再扩张detector；等待最终构建、短段检查和Git检查点。

## 1. 最终系统主张

当前工作最准确的主张是：

> 在ORB-SLAM2 RGB-D上建立了YOLOv8-seg已知人物语义与SInDSLAM风格类别无关区域几何共同参与Tracking、MapPoint写入和动态深度输出的完整实验系统；在TUM人物和Bonn未知箱子代表序列中得到明确正结果，并通过Gazebo/AWS建立逐帧检测、时间支持与自由空间地图的能力边界。

当前不主张：

- 跨场景检测所有未知动态物体；
- 像素级mask精确；
- 简单语义OR几何总是最优；
- 等价复现SInDSLAM全部PEAC、长间隔精修与OctoMap链；
- 在线长期静态地图已经完成；
- 当前CPU区域几何满足30 FPS；
- 提出了区别于SInDSLAM的全新核心detector。

## 2. 正式保留的方法链

```text
RGB-D
├─ YOLOv8-seg person mask：已知动态类别
└─ SIn风格区域几何：3D初始区域、深度梯度切分、RAG合并、
   CPU DeepFlow、homography补偿、区域残差判决、短时时序先验
        ↓
S2 Tracking：动态ORB不参与匹配和后续原生位姿优化
        ↓
S2 fail-open：原生匹配成功条件必然不足时只恢复geometry Tracking标志
        ↓
S2 Mapping veto：动态ORB禁止创建新MapPoint
        ↓
S3 Mapping depth：输出动态深度mask和过滤深度副本
```

没有修改`Optimizer.cc`或g2o，没有对象级BA，没有第三次位姿优化。轻量LK、depth warp、Ji聚类、flood fill和两帧刚性均保留为默认关闭的实验或失败基线。

### 缩写

| 名称 | 含义 |
| --- | --- |
| S1 | SIn风格区域动态检测 |
| S2 | 区域mask进入Tracking和MapPoint写入控制 |
| S3 | 动态深度mask与静态深度副本输出 |
| ATE | 绝对轨迹误差，衡量全局轨迹偏差 |
| RPE | 相对位姿误差，衡量相邻运动误差 |
| RAG | 区域邻接图，用于区域合并 |
| fail-open | 过滤会使原生跟踪条件必败时，临时恢复geometry Tracking观测 |

TUM配置文件名中的`Shadow`是S1开发阶段遗留名称；是否真实进入S2/S3由冻结runner设置的模式决定，不能根据文件名判断。正式统一入口：

```text
DT-SLAM/tools/run_sin_style_mode.py
```

四种模式：

| runner模式 | 语义 | 区域几何 | 对SLAM的动作 |
| --- | --- | --- | --- |
| `orb_baseline` | 关 | 关 | 原始ORB-SLAM2 |
| `semantic_only` | 开 | 关 | person特征与深度过滤 |
| `geometry_only` | 关 | 开 | 区域几何S2/S3 |
| `semantic_geometry` | 开 | 开 | semantic OR geometry基线 |

## 5. 性能结论

AWS平均耗时：CPU DeepFlow约156 ms，深度梯度切分24 ms，RAG合并9.7 ms，区域判决2.5 ms，GPU YOLO约9.6 ms。完整区域几何约3.2–4.6 FPS；含逐帧PNG导出的AWS任务为3.27 FPS。当前性能瓶颈是稠密光流和区域链，不是YOLO或S3 mask应用。

提速研究已经完成文献方向分析，但不属于本次成果收束：不在本检查点替换flow、不加入异步/低频调度、不降低全图分辨率。

## 6. 最小复现命令

### 6.1 构建

```bash
cd /home/zhu/dynaslam_ws/DT-SLAM
make -C build rgbd_tum -j$(nproc)
```

### 6.2 AWS四模式中的组合模式示例

```bash
cd /home/zhu/dynaslam_ws
python3 DT-SLAM/tools/run_sin_style_mode.py \
  --mode semantic_geometry \
  --working-directory /home/zhu/dynaslam_ws/DT-SLAM \
  --binary /home/zhu/dynaslam_ws/DT-SLAM/Examples/RGB-D/rgbd_tum \
  --vocabulary /home/zhu/dynaslam_ws/DT-SLAM/Vocabulary/ORBvoc.txt \
  --base-settings /home/zhu/dynaslam_ws/DT-SLAM/Examples/RGB-D/GAZEBO.yaml \
  --sin-settings /home/zhu/dynaslam_ws/DT-SLAM/Examples/RGB-D/GAZEBO_SInStyleNativeRegionDecisionCPU.yaml \
  --dataset /data/dynaslam/datasets/aws_small_house_person_box_tum_run1_20260806 \
  --associations /data/dynaslam/datasets/aws_small_house_person_box_tum_run1_20260806/associations.txt \
  --model /home/zhu/dynaslam_ws/DT-SLAM/weights/yolov8n-seg.onnx \
  --output-directory /data/dynaslam/large_results/<new_run> \
  --viewer off
```

输出目录必须是新的，runner会拒绝覆盖已有冻结运行。启用`--depth-mask-output-directory`会增加逐帧PNG写盘，不能与正式FPS混用。
