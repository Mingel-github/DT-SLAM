# R6 最终评价范围

日期：2026-08-05

## 1. 目的

R6 不再改算法。它把现有 TUM、Bonn 和 Gazebo 的轨迹、动态特征、深度地图和运行时间
证据分级汇总，明确哪些结论可重复、哪些只是单轮现象，以及当前工作可以怎样写入论文。

## 2. 证据分级

| 等级 | 定义 | 可以支持的措辞 |
| --- | --- | --- |
| A | 同一控制变量至少三轮，结果方向和量级稳定 | 可重复的系统结果 |
| B | 一次完整运行，并有代码不变量、外部序列或直接中间量支持 | 有限系统证据 |
| C | 单次运行或目视/代理评价 | 初步现象，不外推 |
| N | 预设停止条件下的负结果 | 排除当前简化组合 |

## 3. 复用原则

优先复用已经完成且协议明确的运行：

- S2 Bonn nonobstructing 三轮 ON/OFF；
- S2 Bonn obstructing 最终 fail-open 版本；
- 六序列四模式第一轮；
- S3 Bonn/Gazebo 同位姿点云与时间支持体素；
- R0 Gazebo 三轮 ORB/全零语义波动；
- R1/R2/R4 因果审计。

R6 不为了得到更漂亮的数值重复选择序列，不重新调阈值，也不把不同 commit、不同帧范围
或截断轨迹混成同一统计量。

## 4. 最终报告必须包含

- 当前主方法及轻量 LK 的位置；
- TUM/Bonn/Gazebo代表结果；
- ATE、RPE、轨迹完整率和 FPS；
- Tracking 与 Mapping 的直接证据；
- 静态风险和跨域负结果；
- R1/R2/R4 对失败原因的限定；
- 论文贡献强度与不能声称的内容；
- 当前默认开关和使用建议。

ATE 为绝对轨迹误差；RPE 为相邻帧相对位姿误差；FPS 为每秒实际处理帧数。
