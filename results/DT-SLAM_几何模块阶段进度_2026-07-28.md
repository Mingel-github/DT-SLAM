# DT-SLAM 几何动态模块阶段进度

更新日期：2026-07-28

## 1. 总体目标

当前研究路线为：

```text
ORB-SLAM2 RGB-D
+ YOLOv8-seg 语义分支
+ 类别无关几何分支
→ 动态特征与动态深度区域剔除
```

目标是减少：

1. 动态特征参与位姿估计造成的静态背景错位；
2. 动态物体特征或深度写入静态地图造成的残影和拖影。

当前不做：

- 对象级轨迹；
- 对象级 BA；
- g2o 代价函数修改；
- 动态对象地图；
- TSDF、OctoMap 或 3DGS；
- 动态 SLAM 后端重构。

## 4. G0几何证据链

### 4.1 G0-1：单参考帧深度warp

已实现：

```text
上一成功跟踪帧深度
→ 反投影
→ 使用相对位姿变换到当前帧
→ forward projection
→ z-buffer
→ predicted depth
→ signed depth residual
```

残差定义：

```text
r_z = predicted_depth - current_depth
```

解释：

- `r_z > threshold`：当前观测比预测静态表面更近，作为positive seed；
- `r_z < -threshold`：当前观测更远，作为negative/disocclusion诊断；
- 未投影、无效深度和无比较区域：unknown；
- 小残差有效比较：consistent evidence。

该实现是受DynaSLAM多视图深度一致性启发的单参考帧稠密改造，不是DynaSLAM
geometry reproduction。

### 4.2 G0-2：有效性建模

当前几何输出明确分离：

```text
valid comparison
consistent evidence
positive seed
negative diagnostic
unknown/no evidence
```

该设计避免将无效深度、未覆盖区域和遮挡空洞错误解释为静态证据。

### 4.3 G0-2C：坐标域和畸变

已经明确：

- TUM3使用零畸变针孔模型；
- TUM1 Tracking保留原生非零畸变RGB标定；
- TUM1 raw registered depth geometry使用TUM推荐的零畸变
  `fx=fy=525, cx=319.5, cy=239.5`；
- semantic mask与`Frame::mvKeys`位于原始RGB像素域；
- Optimizer主要使用`Frame::mvKeysUn`。

Bonn具有非零畸变，在没有统一RGB/depth/mask坐标域前，不能直接使用当前raw
pinhole warp评价几何效果。

### 4.4 G0-2P：SLAM pose与GT pose

在相同深度数据上同时使用：

```text
ORB-SLAM2当前位姿
数据集GT位姿
```

结果显示GT pose没有系统性降低positive seed。当前背景seed不能主要归因于
ORB-SLAM2位姿误差，但仍可能同时受到以下因素影响：

- 深度边界和空洞；
- RGB-depth时间差；
- 遮挡和显露；
- forward rasterization；
- 深度噪声；
- 标定近似。

## 6. G0-3/G0-3R失败实验

### G0-3

从所有positive seed出发，按相邻深度差小于固定阈值进行四邻域传播。

失败表现：

- region覆盖valid comparison约95%–97%；
- seed到region面积放大约27–31倍；
- walking和sitting场景的region统计明显重叠。

原因是：

```text
局部相邻深度连续
≠
属于同一个运动对象
```

墙面、地面、斜面和家具表面可以通过一系列小深度差形成巨大连通分量。少量错误
seed落入这些连通分量后，会触发整片区域传播。

### G0-3R

尝试加入区域positive support、面积和残差统计，但没有解决传播结构问题。

冻结结论：

```text
G0-3/G0-3R = 已完成的失败baseline
默认关闭
不得进入mvbDynamic
```

不再通过继续调整面积、seed ratio或固定阈值掩盖失败。

## 8. 相对初始计划的调整

### 8.1 人工标注改为自动代理审计

原计划考虑少量人工动态区域标注。实际改为：

- 离线person proxy mask；
- 自动precision/recall统计；
- 自动CSV、overlay和日志；
- 静态序列作为负样本对照。

这样减少了用户人工工作量，但最终论文级motion mask评价仍需要合适真值数据。

### 8.2 区域生长不再直接进入基础版本

原设想：

```text
positive seed → depth region growing → dynamic region
```

实验表明该组合不成立，因此region growing不再作为未经验证的默认步骤。

### 8.3 特征标记改为先做shadow门控

原计划可能直接给ORB特征设置几何动态状态。实际先完成G0-4F诊断，结果没有通过
precision门控，因此没有写入`mvbDynamic`。

### 8.4 DynaSLAM/ReFusion传播规则继续暂缓

两种文献传播方法都依赖更高质量的输入seed。当前seed本身定位能力不足，直接更换
传播函数只能形成错误输入上的局部消融，不能解决主要问题。

### 8.5 不增加第三次PoseOptimization

保持ORB-SLAM2已有优化路径，当前geometry只做shadow，没有修改`Optimizer.cc`
或无条件增加额外位姿优化。

## 12. GJ-1/GJ-2A结果与下一阶段

GJ-1已经独立实现Ji 2021的三维深度K-means区域生成。TUM fr3/walking与
fr1/xyz短序列中，每帧均得到24个非空cluster；可视结果符合“空间邻近表面分区，
一个对象可能跨多个cluster”的文献边界。

```text
fr3/walking GJ total mean: 57.84 ms
fr1/xyz GJ total mean: 58.45 ms
fr3/walking actual FPS: 12.56
```

因此GJ-1可以作为论文比较baseline，但当前全分辨率CPU K-means不能作为30 Hz主
方法。GJ-2也已完成：

```text
ORB feature -> raw-depth cluster
MapPoint + Tcw -> undistorted reprojection error
cluster support/error shadow statistics
```

GJ-2统计自身仅约0.023–0.028 ms。GJ-2A已经使用100帧walking离线person
proxy完成自动审计：

```text
全局Spearman(mean squared error, proxy fraction) = 0.308
Top-3 proxy capture = 36.05%
Top-3 area fraction = 19.10%
Top-3 random enrichment = 2.14×
逐帧Top-3 enrichment > 1: 85/99
```

optimizer outlier fraction的Top-3 capture仅为20.50%，说明cluster error不是简单
复述已有离群比例。但walking与fr1/xyz静态误差仍重叠，静态cluster mean error
最大值也达到约50 px。

因此GJ-2A通过的是“存在排序信号”门控，不是“动态阈值可靠”门控。继续执行边界：

1. 仍保持shadow-only；
2. 没有地图匹配支持的cluster标为unknown，不能标为static；
3. 不凭空补写论文未公开的`rho`、最小支持数或动态阈值；
4. 不与当前失败的flood fill混成一个算法；
5. 不修改Optimizer、g2o或后端；
6. 任何未来GJ实际过滤都需重新审批，当前GJ-3A适配已判定失败；
7. Ji baseline仍不满足30 Hz，主方法不采用全分辨率CPU K-means。

GJ-3P进一步核对了本地PaperNotes、论文PDF、官方arXiv源码包、IEEE元数据和
公开代码检索。确认论文只说明“选择较低阈值，阈值取决于匹配特征的平均重投影
误差”，没有给出`rho`形式、阈值函数/数值或最小支持数。因此严格二值判定无法
从公开材料补齐。未来若继续，只能建立单独标记为`GJ-A`的相对阈值适配shadow。

GJ-3A随后固定了`mean_squared_error_px2`、两种frame mean normalization、对数
lambda网格和calibration/validation拆分。两种normalization都在calibration选择
`lambda=0.5`，dynamic validation F1约`0.51`，但fr1/xyz静态选择面积约
`50%–54%`；同相机的fr3/sitting低动态诊断也约`50%–52%`。提高lambda会同时
快速压低动态召回，没有观察到明显可用工作点。因此GJ-3A冻结为负实验，不进入
实际动态cluster过滤。

## 13. G2-1多参考证据结果

G2-1根据DynaSLAM公开的“20帧参考数据库、最多5个参考帧”设置，建立了明确标记
为改造而非复现的shadow：

```text
最近5个成功关键帧
→ 复用G0稠密depth warp
→ 每像素comparison/positive/negative/consistent计数
→ 只保存二维直方图，不做动态决定
```

walking的离线person proxy审计显示，多参考重复证据比G0单参考直接seed更集中：

```text
C>=1, P>=1: precision 34.41%, conditional recall 23.77%
C>=2, P>=2: precision 38.54%, conditional recall 16.82%
C>=5, P>=2: precision 40.46%, conditional recall 17.60%
```

对应的fr1/xyz静态选择率分别约为`7.06%`、`2.65%`和`2.41%`。继续提高一致
票数虽然能压低静态选择率，但会使proxy recall快速降至约`10%`以下，因此尚未
观察到足以批准实际过滤的工作点。

实时性方面，5次全分辨率稠密warp本身平均约`20–23 ms`，三个短序列的端到端
实际速度约`20.96–22.17 FPS`，明确不满足30 FPS目标。该实现保留为shadow
对照，不进入同步主路径。

此外，sitting中曾长时间没有新关键帧，导致“最近关键帧”与当前帧相隔较远。
下一步必须把参考重叠、时间跨度和有效覆盖作为独立研究问题，不能直接把关键帧
票数解释为时序确认。

RTX 4060 Ti恢复后又完成三个199帧在线同步语义闭环。三次均为
`mask ready=199/199`、`mask age median/max=0/0`。在线G2-1耗时为：

```text
walking: 14.02 ms mean, 20.70 FPS end-to-end
```

## 28. G2-4B Bonn坐标域审计与最小一致域规格

只读代码审计纠正了一个容易误述的点：

```text
Frame::ComputeStereoFromRGBD:
  depth在raw mvKeys位置读取；
  mvKeysUn用于去畸变后的针孔投影。
```

因此当前RGB-D feature depth路径本身不是“用undistorted keypoint读取raw
depth”。真正冲突是geometry warp直接把raw depth pixel当无畸变针孔域，而
Bonn官方相机具有非零distortion。

`[S]` 用官方`K,D`测得raw-to-undistorted像素偏移median `0.675 px`、
P95 `1.208 px`、max `4.227 px`，不能相对当前1/2-pixel risk band忽略。
该测量不证明动态精度会提高或下降。

冻结最小候选：

```text
RGB:   official K,D -> P=K linear rectification -> YOLO + ORB
depth: official K,D -> P=K nearest rectification -> tracking + geometry
mask:  YOLO直接在rectified RGB上产生
SLAM:  K=official K, distortion=0
```

这是`[A/S/H]`组合，不是论文整体复现。`P=K`网格审计显示99.401%输出像素
映射到图像内source，但这不等于有效depth retention或对象边界正确，仍需真实
样本门控。

本地archive审计还发现：

```text
moving_nonobstructing_box: depth.txt比实际depth PNG多4项
moving_obstructing_box:    depth.txt比实际depth PNG多3项
```
